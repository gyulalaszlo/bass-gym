# bass-gym

Read `docs/architecture/README.md` before exploring the code. It indexes notes on the
audio engine, UI and data model, and these usually answer the question without a broad
code read. Open only the source files you then need.

Keep those docs true: when a change makes one wrong, update it in the same commit. If
you find a doc that disagrees with the code, trust the code and fix the doc.

Commands, debug variables and conventions are in `docs/architecture/README.md`.
